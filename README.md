# CHIMIRA: Roblox 2021 Client Preservation

This repository documents a personal software preservation project focused on the Roblox Windows client from early 2021.

The main target is:

- Roblox WindowsPlayer
- Version: `0.472.0.419960`
- Deployment: `version-0137f7d4848f436a`
- Release period: March 2021

## Goal

The goal of this project is to research and preserve the historical Roblox Windows Desktop Beta experience from 2021, including its old desktop app interface and onboarding flow.
A particular focus is the historical signup experience that allowed new users to choose from multiple starter avatars. [![This one](https://img.youtube.com/vi/hn0i0Fufm_Q/maxresdefault.jpg)](https://www.youtube.com/watch?v=hn0i0Fufm_Q)
This is intended as an offline historical preservation project, not as a public Roblox revival or replacement service.

## Research

The project involves researching and documenting:

- Historical Roblox deployment manifests
- Original Roblox client packages
- Archived Windows client binaries
- Package hashes and version identifiers
- Historical sandbox analysis reports
- Roblox Desktop Beta files and UI resources
- LuaPackages and other client-side application resources


This project is for historical research, documentation, and software preservation.
This repository does not distribute Roblox client binaries, copyrighted Roblox assets, account credentials, authentication tokens, or a public Roblox revival service.
